TEACHER FILE / HOW TO USE

Four 37-minute investigations for 45-minute classes. Students work through briefings, simulations, evidence, and written reports. Each mission matches one section of the printable PDF packet.

Google Sheets: This file works offline. To send answers to a Sheet, deploy this same file as Index.html in Google Apps Script with the included Code.gs. Then the final Submit button sends one report to the spreadsheet.

Science: Numerical simulation readings are learning models, not measurements of Runner #0358. Her medical-chart values are the real case-data values supplied in the New Visions packet.

Records: A report saved locally is not a submitted lab report. Have students print/download and turn in work, or use the connected Google version. Review for satisfactory completion and log actual minutes.
