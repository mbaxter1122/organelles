# Cell Explorer

Click a part of the animal or plant cell to see it float out, watch a looping GIF of its job, and complete two written responses: identify its function and answer a question about that function. Includes worksheet colors, read-aloud descriptions, reduced-motion step controls, and printable responses.

Animal: cell membrane, nucleus, mitochondria, cytoplasm, ribosome.
Plant: the same five, plus cell wall and chloroplasts.

## Student work
Work stays in the current browser page and clears on refresh or close. Students should print or save as PDF before leaving. No answers are sent to a server or automatically submitted to Google Classroom. Completion checks whether both fields are filled; it does not grade scientific accuracy.

## Hosting
Enable GitHub Pages from main, / (root). No build or external libraries are required.
